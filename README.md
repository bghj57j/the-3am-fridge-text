What this is: one short message from a smart fridge to its owner, sent at 3am. The fridge has watched the household all week — it saw the diet arrive on Monday and leave on Tuesday — and it is done keeping quiet about the cake.

Running `main.py` drops the message into `/output/entry.txt` (or wherever `MAKEFUN_OUTPUT_DIR` points). The text is exactly 100 characters, inside the 1–140 gate.

The message:
> 3am again. I saw the diet start on Monday. I saw it end on Tuesday. The cake is on the second shelf.
